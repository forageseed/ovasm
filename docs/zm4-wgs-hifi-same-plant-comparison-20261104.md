# ZM4 同株 WGS／HiFi 组装对照（2026-11-04）

用户已明确确认：SRR13333747 WGS 与单独留出的 ZM4 HiFi（目录
`hifi-latest-ZM4-74e0cf7`）来自同一植株。此前报告中关于这两份数据是否同株
的疑问撤销。本次确认不涉及另外八组 HiFi 先验与核参考单倍型的样本身份，
也不把每一条同源读段自动认定为细胞器来源。

本次只读比较已有组装，不重新组装、不据 HiFi 答案调整 WGS 排名。
数据包括完整可用前缀 WGS 运行 `v20-wgs`、后续已招募读段回放
`origin-fields-target-replay`，以及原有 ZM4 HiFi 组装。

## 为什么默认代表还不一样

后续回放中，默认第 1 号线粒体候选与匹配 HiFi 的第 11 号候选，目标 WGS
分数都约为 -6.9314718056、拷贝偏差均为零。它们的区别来自八组其他 HiFi
先验的启发式支持分：分别为 0.4125 和 0.375；联合路径支持的样本数分别为
4 和 3。组合分分别为 -6.5189718056 与 -6.5564718056。

因此，现有候选生成已经包含与同株 HiFi 代表逐碱基一致的线粒体表示，默认
启发式排名却没有优先选它。不能把跨样本先验给出的轻微分差当成目标植株
拓扑的确定结论，也不能仅因对照知道答案就修改这次测试的排名。

原 HiFi 线粒体组装本身也记录 `decisive=false`，另有同株 HiFi 读段支持
多个局部连接组合。完全匹配其两条代表记录不证明真实样本只含两个环状分子。
同株身份让 HiFi 成为更直接的连接对照，但这些已检查过的数据不再是未触碰的
盲测集。
