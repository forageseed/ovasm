# Original-read support for connections hidden by long k

Sparse HiFi assembly now checks for structural connections hidden inside a
unitig by an inverted repeat shorter than the graph k. Long error-free k-mer
counts can omit such a connection even when many original reads span it.

The assembler enumerates maximal sub-k inverted repeats from its own backbone.
It builds competing normal and inverted contexts and uses the existing HiFi
evidence preset: k21 words, 2,000-bp flanks, 500-bp anchors, 30-bp diagonal
tolerance and 0.05 spacing tolerance. Each connection must independently reach
the **unchanged assembly min-count**, using distinct original record IDs. An
identical duplicate record cannot increase support; conflicting complete records
with the same ID are an error. Ambiguous contexts cannot vote for a connection.

The check uses the original input records even if the automatic k ladder needed
corrected reads to build the backbone. Dense short-read assembly is unchanged.
It does not use another assembler's graph, a truth sequence, or a lower count
fraction to select connections.

When a connection passes, original nodes are split at its attachment coordinates
and a short context bridge is added. Every original base and adjacency remains.
`assembly.backbone.gfa` retains the graph before this addition. Bridge tags `JS`
and `NS` record alternative and normal complete-read counts. `JR` identifies the
read-backed alternative. Its depth is the parent depth multiplied by its observed
alternative fraction, rather than a raw read count substituted into k-mer-depth
units. Duplicated context in a bridge is **not extra unique mitochondrial DNA**.

`assembly.json:junction_rescue` retains the hypotheses, support counts, read IDs,
query coordinates, rejection reasons and original automatic support threshold.
The representative FASTA may use the major configuration while the GFA retains
supported alternatives. Two independently supported connections do not establish
a jointly phased inversion or physical circular molecules.

## Whole-read nuclear context

Both public commands accept an optional evidence file:

```sh
ovasm run --reads recruited-mt.fastq --read-set target --read-type hifi \
  --organelle mitochondrion --read-context complete-read-context.json --out result

ovasm assemble --reads recruited-mt.fastq --read-context complete-read-context.json \
  --out assembly.gfa --out-json assembly.json
```

The JSON schema `ovasm.whole-read-context.v1` contains `records`, each with:

| Field | Meaning |
| --- | --- |
| `read_id`, `query_sequence` | Original ID and complete original read sequence |
| `query_start`, `query_end` | Zero-based half-open aligned query interval |
| `strand` | `+` or `-` relative to the reference |
| `reference_name`, `reference_start` | Supplied nuclear reference and aligned start |
| `reference_sequence` | Exact aligned substring, forward in reference coordinates |
| `cigar` | Target-forward extended CIGAR using `=`, `X`, `I`, `D` |
| `junctions` | Optional query intervals to audit without inventing new assembly hypotheses |

The implementation checks the CIGAR against the actual complete query and
reference DNA, including negative-strand coordinate conversion. A participating
input record must exactly match the supplied complete query. Whole-read query
coverage and identity must meet the existing HiFi evidence tolerance (0.95).
The same continuous alignment must contain at least 500 aligned bases of
target-absent nuclear context on **each** side of the tested connection.
Words found anywhere in the current backbone or across its existing edges count
as target DNA. Shared sequence and a short nuclear match do not establish origin.

Only a record with that bilateral nuclear-context evidence is excluded from the
organelle vote for the connection. All witnesses and source status remain in the
report; original shared backbone sequence is not deleted. Missing context stays
unknown. Supplied junction audits are reported separately from connections
generated by the assembler. The evidence file must retain its reference,
alignment and complete-record provenance; a supplied reference label is not a
certificate of physical origin.

The present hypothesis generator covers internal sub-k inverted repeats with
room for both anchors. It does not recover every possible structural variant,
resolve connections too close to an existing graph-end overlap, or certify
physical chromosome number/topology.

## Development validation

On the already-seen ZM4 fixed recruited HiFi input, k1001 and automatic min-count
53 remained unchanged. Two alternative connections had 106 and 339 distinct
complete-read witnesses and were retained. Ten other repeat hypotheses had
insufficient support. The graph became nine nodes and twelve links. Its original
backbone and representative sequences (160,953 and 146,073 bp) were unchanged;
the plastid sequence remained 125,509 bp. Seventeen other already-seen fixed
recruited HiFi inputs retained their backbone GFA and representative sequences
exactly. These are development regressions, not independent truth validation.
