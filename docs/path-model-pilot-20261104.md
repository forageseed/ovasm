# OVASM 复杂图路径模型：第一轮测试（2026-11-04）

本轮完成了独立、可重跑的候选路径审计，没有替换默认组装或线性化评分。结论是：联合读段路径有额外辨别力，闭合应依赖连接证据；现有真实数据仍不能裁决唯一构型。不能据此宣称提高了完整组装准确率或确定物理染色体数。

## 实现与范围

正式仓库：`/home/jiazc/data24t/work-live/PhytoOrga_AI_c/ovasm`。

- `scripts/audit_path_models.py`：读取同一图的 evidence 和 linearization，重新审计候选。要求两份报告记录的原图仍存在，并与输入 GFA 的 SHA-256 完全一致；校验节点、边和路径有效性。
- `scripts/run_path_model_pilot.py`：在服务器上运行可复现的原生模块对照和真实图候选重建。
- `tests/test_audit_path_models.py`：10 个行为测试。

审计将局部三节点穿行、单记录最大连续路径、跨至少两个不同分叉节点的联合路径分别统计。匹配考虑反向互补，仅圆形候选允许跨首尾。探索性排序依次比较联合路径、完整路径、局部穿行支持，再比较弱连接/纯拓扑连接数和拷贝偏差；圆形、分子数、序列长度没有额外奖励。

该排序是显式的启发式，不是似然、后验概率或丰度模型。其计数单位为“记录—路径出现次数”：重叠路径可能来自同一记录；旧 evidence 不保证跨输入全局去重，不认证嵌合排除或细胞器来源。联合证据与局部证据不相加解释为独立观测。输出始终保留 `physical_topology_identified=false`。

## 已完成验证

正式目录中的 10 个行为测试全部通过，覆盖链方向、首尾跨越、局部相同而联合不同、混合构型保留并列、原图序列/连接不匹配、重复观察拒绝、截断状态保留和计算预算耗尽。

使用与正式源码全量哈希匹配的冻结二进制运行原生 `check evidence`，完成以下四个断言对照：

| 对照 | 结果 |
|---|---|
| 两个候选的局部穿行支持完全相同 | 局部计数均 60；正确联合组合匹配 20 次完整路径，错误组合 0 次 |
| 两套联合组合以相同数量共存 | 保持两个候选并列，不制造唯一解 |
| 有开放路径读段，没有首尾跨越读段 | 开放与闭合候选并列，闭合不额外加分 |
| 加入首尾跨越读段 | 闭合候选因解释额外连接证据获得更高支持 |

前四项的候选路径是为已知对照手工指定的，证据由原生 Rust 模块从合成 DNA 读段生成。联合对照使用刻意未压缩的图验证路径关联；这些测试不是端到端模拟组装准确率评估。

另运行一次原生求解器的重复连接烟雾测试：得到两条线性代表路径，没有出现需要纠正的优先闭合。此为阴性对照，不把原先怀疑的闭环偏好描述为已证实错误。

  --gfa /absolute/path/assembly.gfa \
  --evidence /absolute/path/evidence.json \

  --out /absolute/path/path-audit.json

## 推进决定

保留当前默认评分，把本轮代码作为可用的独立研究诊断。下一项采用门槛是：同一标本的原始长读段、严格记录去重与歧义处理，以及留出数据上的预先固定规则对照；同时测序列召回和错误连接。先补齐这些证据，再判断是否把联合路径评分接入默认求解器。不能为了减少并列候选而调阈值或使用其他个体的主构型代替目标样本真值。
