# OVASM 0.2.0

## Ready-to-run packages

- Linux x86_64, glibc >=2.34, native multichrom kernel included.
- Windows x86_64, static CRT, portable stages. Unzip and double-click install.cmd.
- SHA256SUMS and checksum-verifying installers; no Rust or C compilation for users.
